# 🛒 Amazon Frontend Clone

A frontend clone of Amazon built to practice web development and improve my HTML and CSS skills.

## 🚀 About the Project

This project recreates the basic design and layout of Amazon's website, including its navigation bar, search bar, product sections, and more.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Amazon-inspired navigation bar
* Search bar
* Product sections and product images
* Responsive layout (if implemented)
